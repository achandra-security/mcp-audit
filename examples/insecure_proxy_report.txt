mcp-audit assessment report
===========================

configs/insecure_proxy.json: 21 finding(s) (critical=5, high=10, medium=5, low=1)

  [CRITICAL] MCP-003 Remote MCP server without OAuth authorization
    server:      legacy-files
    target:      auth
    evidence:    streamable-http transport at http://files.example.test:8080/mcp with auth.type=none
    remediation: Protect remote MCP servers as OAuth 2.1 resource servers. Replace static shared tokens with short-lived, audience-bound access tokens.
    references:  MCP specification 2025-06-18, Basic > Authorization; RFC 9700: Best Current Practice for OAuth 2.0 Security

  [CRITICAL] MCP-005 Token audience is not validated or is too broad
    server:      crm-proxy
    target:      auth.audience
    evidence:    validate_audience=false
    remediation: Accept only tokens whose 'aud' is this MCP server's canonical URI. A token minted for another service must be rejected, even when it comes from the same issuer.
    references:  MCP specification 2025-06-18, Basic > Authorization; RFC 8707: Resource Indicators for OAuth 2.0; RFC 9068: JWT Profile for OAuth 2.0 Access Tokens (iss/aud validation)

  [CRITICAL] MCP-007 Inbound access token is passed through to downstream APIs
    server:      crm-proxy
    target:      auth.downstream
    evidence:    token_passthrough=True, downstream_auth=passthrough
    remediation: Never forward the client's token downstream. Exchange it for a new token scoped to the downstream audience (RFC 8693 token exchange), or use the server's own credential with per-user authorization.
    references:  MCP specification 2025-06-18, Basic > Security Best Practices; RFC 8693: OAuth 2.0 Token Exchange

  [CRITICAL] MCP-012 Destructive tool does not require human approval
    server:      crm-proxy
    target:      tool:delete_account
    evidence:    destructiveHint=true; requires_approval=false; scopes ['crm:*']
    remediation: Require explicit human confirmation, bound to the specific call, for destructive tools. Enforce it in the host or gateway, not in the tool description.
    references:  MCP specification 2025-06-18, Server > Tools (tool annotations); OWASP Top 10 for LLM Applications 2025: LLM06 Excessive Agency

  [CRITICAL] MCP-014 Resource outside declared access boundary
    server:      legacy-files
    target:      root:file:///
    evidence:    allowed root is the entire filesystem
    remediation: Declare narrow allowed roots. Canonicalize every resource URI before the boundary check, and reject traversal segments.
    references:  MCP specification 2025-06-18, Server > Resources; OWASP Top 10 for LLM Applications 2025: LLM06 Excessive Agency
